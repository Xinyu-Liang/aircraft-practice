# 四轴无人机开发记录

这个仓库用于记录四轴无人机的制作过程，包括设计思路、硬件选型、电路绘制、制作记录、测试结果和相关代码。

## 项目目标

制作一架可以稳定飞行的四轴无人机，并在制作过程中学习飞控、电机、电源、传感器、无线通信和飞行动力学等相关知识。

## 系统组成

### 飞控系统

飞控系统以 STM32F103C8T6 作为主控芯片，用于处理传感器数据、通信数据和飞行控制逻辑。

### 姿态检测系统

姿态检测系统采用 MPU6050，用于测量无人机的飞行姿态。飞行姿态可以通过欧拉角进行描述，主要包括：

- Pitch：俯仰角
- Yaw：偏航角
- Roll：横滚角

### 无线通信系统

无线通信部分用于实现无人机与遥控器之间的数据传输。目前学习和设计中涉及 2.4G 无线通信模块，包括 NRF24L01 和 SI24R1，通信接口主要采用 SPI。

### 电源系统

电源系统用于为飞控、传感器、通信模块和其他硬件提供稳定电压。目前记录中涉及：

- 锂电池
- IP5305T 电源芯片
- AMS1117-3.3V 线性稳压器

### 动力系统

动力系统用于提供无人机飞行所需的升力。目前学习中涉及空心杯直流电机，并通过 PWM 和 MOS 管控制电机输出。

### 机架结构

无人机机架采用 X 型四旋翼结构。该结构通过四个电机的不同转速组合，实现上升、下降、悬停、偏航、俯仰和横滚等飞行动作。

- 了解 STM32F103C8T6 主控芯片
